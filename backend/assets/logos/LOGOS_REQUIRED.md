# Logos Required — Manual Export from Figma
Before running the application, export these 6 files from Figma:
- nowpurchase_white.png (280×72px, transparent bg, white wordmark)
- nowpurchase_dark.png (280×72px, transparent bg, dark wordmark)
- metalcloud_white.png (horizontal, transparent bg, white wordmark)
- metalcloud_dark.png (horizontal, transparent bg, dark wordmark)
- combined_white.png (pre-designed lockup, both logos, white)
- combined_dark.png (pre-designed lockup, both logos, dark)
Place all 6 files in this directory before starting the server.
